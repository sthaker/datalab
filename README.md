# Data Lab

A small page of short, self-paced data lessons for two kids, with a check at the end of each one. It is a home curriculum in reading graphs, collecting data and basic statistics, built to run next to school in 10 to 15 minutes, three times a week.

Live: <https://sthaker.github.io/datalab/>

Who it is for: a 7th grader and a 4th grader working mostly alone, and their parents, who set it up and spot-check. Anyone can open the page and use "Grown-ups: try the lessons" to see every session; nothing is saved.

The page holds lessons only. Names and progress are stored separately, in a private place the family controls.
